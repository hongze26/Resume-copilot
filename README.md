# 网申助手 · Resume-copilot

装在 Chrome / Edge 里的网申填表助手：把简历整理成一份**只存在本机**的档案，在招聘网站填简历时**先给你预览、你确认后再填**。保存、提交、投递永远由你自己点。

![侧边栏预览：每个字段填什么、把握程度、依据](docs/images/04-panel-preview.png)

## 它保证什么

| 保证 | 怎么做到的 |
|---|---|
| 资料不出本机 | 档案存在浏览器的本地存储里；安装时不申请任何网站权限；打包前有脚本检查联网入口。可选的大模型 API 默认关闭，每次发送前给你看要发的内容 |
| 永不自动提交 | 代码里拒绝点击“保存 / 提交 / 投递”类按钮，填写期间拦截表单提交；每个端到端测试都断言这两项为 0 |
| 不确定就告诉你 | 每个字段标“高 / 中 / 低 / 跳过”并写明原因；政治面貌、婚姻、户口等敏感项只在完全确定时才填 |
| 默认不覆盖 | 网页上已有内容的栏目跳过；撤销只恢复它自己写入、你之后没改过的栏目 |
| 不替你写字 | 自我评价等长文本只原样插入你自己写好的内容 |

## 支持哪些网站

| 网站 | 方式 | 验证到什么程度 |
|---|---|---|
| 智联校园网申“填写简历”页（`xiaoyuan.zhaopin.com/scrd/resume*`） | 专用适配 | 在真实页面上核对过全部区块的结构，并试填过部分区块 |
| 国聘“申请简历”页（`*.iguopin.com`） | 专用适配 | **只在按页面结构重建的本地测试页上验证过，没有在真实页面上试过** |
| 其他招聘网站（企业官网、“我的简历”简历中心等） | 通用识别 | 在真实的 antd 5、Element UI 1.4 / 2.15 组件库搭的测试页上验证；具体网站效果不一 |
| 通用识别对不上的网站 | 定制适配器 | 用你自己的大模型 API 根据页面结构生成字段对应关系，复核后保存；只用模拟接口测过 |

能填写的控件：原生表单、antd、Element UI 1.x / 2.x。其他组件库的文本框能填，下拉和日期可能要手选。详细边界见[已知限制](docs/已知限制.md)。

## 安装

1. 在 [Releases](../../releases) 下载最新的 `resume-copilot-v*.zip`，解压到一个固定位置。
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），开启“开发者模式”。
3. 点“加载已解压的扩展程序”，选解压出来的文件夹。

然后看[快速上手](docs/快速上手.md)（一页）。完整说明：[安装说明](docs/安装说明.md)、[使用手册](docs/使用手册.md)。

需要 Chrome 116 及以上，或新版 Edge。

## 使用边界与免责声明

- 本项目是个人开源项目，**与国聘、智联招聘及任何招聘网站没有关联**，也未获得它们的认可。网站改版后适配可能失效。
- 工具只在你自己已登录的浏览器会话里，替你填写你本人的资料。它不自动登录、不处理验证码、不绕过任何访问控制、不批量或自动投递。
- 填写结果不保证正确。**保存前请逐项核对**，填写内容和投递行为由使用者本人负责。
- 使用前请自行确认符合所用招聘网站的用户协议。
- 测试页面（`tests/fixtures/`）是按公开可见的页面结构自行重建的，只用于兼容性测试，不含任何网站的代码或样式。测试简历中的人物均为虚构。

## 开发

```bash
npm install
npx playwright install chromium
npm run typecheck      # 类型检查
npm test               # 单元测试
npm run test:e2e       # 构建测试版扩展和测试页，跑端到端测试
npm run package        # 发布构建 + 网络检查 + 打 zip
```

`npm run build` 产出 `dist/`，可以直接在扩展管理页加载。

```
src/
├─ core/            纯逻辑：档案、归一化、字段匹配与打分、填写计划、简历识别
├─ adapters/        站点规则：国聘、智联校园、通用识别、定制适配器
├─ content/         内容脚本：区块与表单定位（site/）、控件识别（scan）、控件驱动（drivers/）
├─ pages/panel/     侧边栏：扫描 → 预览 → 确认 → 填写 → 结果 → 撤销
├─ pages/profile/   档案管理页：录入、简历识别、导入导出
└─ background/      Service Worker（只负责打开侧边栏）
tests/              单元测试、端到端测试、测试页面、虚构测试简历
```

内容脚本只上报页面**结构**，不接触档案；匹配在扩展页面里完成；执行时只下发你确认过的字段和值。架构、目录速查和常见改动见[开发者指南](docs/开发者指南.md)，测试说明见[测试方法](docs/测试方法.md)。
