# 快速上手（一页版）

网申助手是装在 Chrome / Edge 里的小工具：把你的简历整理成一份只存在本机的档案，在招聘网站填简历时替你把能对上的栏目填好。**它只填写，保存、提交、投递都由你自己点。**

详细说明见 [安装说明](安装说明.md) 和 [使用手册](使用手册.md)。

## 一、安装（约 3 分钟，只做一次）

1. 把安装包 `resume-copilot-v0.9.0.zip` 解压到一个固定位置，例如 `D:\网申助手`。以后不要移动或改名。
2. 浏览器地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`），打开 **“开发者模式”**。
3. 点 **“加载已解压的扩展程序”**，选刚才那个文件夹。
4. 点工具栏的拼图图标，把“网申助手”固定到工具栏。

## 二、建档案（只做一次）

1. 点工具栏的网申助手图标 → 侧边栏右上角 **“档案管理”**。
2. 点 **“选择简历文件”**，选你的 PDF 或 Word（.docx）简历。工具会在本机识别出姓名、教育、实习、证书等，弹出清单。
3. 勾选要填入的项 → **“填入选中的 N 项”**。黄色底的是刚填进来的，逐项看一遍，错的直接改，缺的手动补。日期尽量写到日。
4. 点 **“保存”**，再点 **“我已核对”**。
5. 点 **“导出备份”**，把备份文件存好。

## 三、在招聘网站上填写（每次都是这几步）

1. 自己登录招聘网站，打开填简历的页面。
2. 点工具栏图标打开侧边栏 → **“扫描本页”**。第一次会问两次权限（读取网址、访问这个网站），都点允许。
3. 侧边栏按区块列出要填的内容：
   - 基本信息这类单项区块：点 **“展开编辑表单并扫描”**。
   - 教育、实习这类多条的区块：点 **“添加并准备第 N 条”**。
4. 看预览。**高** 是确定的；**中** 是大致对得上、先替你选了最接近的，旁边写着原因；**低 / 跳过** 不填。不想填的取消勾选。
5. 点 **“填写选中的 N 项”**。
6. **在网页上把这一条看一遍，没问题再自己点网页上的“保存”。** 经历类保存后，侧边栏会自动转到下一条。
7. 填错了点 **“撤销本次填写”**。

三类网站用法相同：国聘“申请简历”页和智联校园网申页有专门适配；其他网站用通用识别，换一个子页面要重新点一次“扫描本页”。

## 四、一定要记住的四件事

1. **填完要自己核对。** 工具填的不保证全对，标“中”的尤其要看。
2. **这些要自己填：** 证件号码、证件照和附件、家庭成员、声明勾选、验证码。
3. **升级不要点“移除”。** 新版本解压后覆盖原来的文件夹，再到扩展管理页点刷新 ⟳。点了“移除”，档案会被清空。
4. **定期“导出备份”。** 备份文件是明文，含个人信息，只存在自己的电脑或 U 盘里。卸载扩展前一定先导出。

## 五、常见情况

| 现象 | 怎么办 |
|---|---|
| 侧边栏显示“读取不到当前网页的地址” | 点“允许读取当前网页地址”，在弹窗里点允许 |
| 提示“页面没有响应” | 刷新网页，再点“扫描本页” |
| 某一栏总是填不上 | 看结果里写的原因，手动填这一栏 |
| 简历识别得很乱（表格式、图片式、英文简历） | 直接在档案页手动录入；扫描版 PDF 认不出文字 |
| 升级后档案不见了 | 多半是点过“移除”，或者是从 0.8.1 及更早版本升上来的。在档案管理页用“导入 JSON”把备份导回来 |
| 一个网站大部分栏目都对不上 | 可以生成“定制适配器”（需要自己的大模型 API），见使用手册第四节 |
