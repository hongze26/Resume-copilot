# 测试方法

## 环境

- Node.js 20 及以上（开发时用的是 24）
- 首次运行：`npm install`，然后 `npx playwright install chromium`

## 命令

| 命令 | 内容 |
|---|---|
| `npm test` | Vitest 单元测试（`tests/unit/`，core 纯逻辑：归一化、冲突对、敏感规则、Schema、迁移、脱敏） |
| `npm run typecheck` | TypeScript 严格模式类型检查 |
| `npm run test:e2e` | 构建测试版扩展和夹具，用 Playwright Chromium 加载扩展跑端到端验收 |
| `npm run test:e2e:edge` | 同一套端到端测试，用本机 Microsoft Edge 跑 |
| `npm run check:network` | 构建期网络入口与权限检查（需先 `npm run build`） |
| `npm run package` | 构建、网络检查、打包 `release/resume-copilot-v<版本>.zip` |
| `node scripts/make-test-resumes.mjs [目录]` | 把 `tests/resumes/*.txt`（虚构简历）生成为 `.docx` 和 `.pdf`（默认输出到 `tests/resumes/out/`） |
| `node scripts/screenshots.mjs` | 重新生成文档截图（需先 `npm run build`、`npm run build:test`、`npm run build:fixtures`） |

## 本地夹具

- `tests/fixtures/gp-like/`：按国聘材料**自行重建**的 React 18 + antd 5 表单。只复用字段名、选项和结构，不包含国聘的 CSS/JS。包含锁定字段、条件字段（专升本/双学位/研究方向）、远程学校搜索（400ms 延迟）、异步三级省市区、“至今”、保存后的记录列表。
  - `?prefill=1`：基本信息预填邮箱（测“不覆盖”）。
  - `?variant=ambiguous`：学历选项含“研究生”（测歧义）。
  - `window.__fixture`：保存/取消按钮点击数、submit 事件数、各表单的 React 状态、已保存记录。
- `tests/fixtures/native/`：原生表单（label[for]、aria-label、包裹式 label、表格布局、原生 radio/select）。`edit-mode.html`：单项区块先显示为只读文字、点“编辑”才出现输入框；经历记录旁也有“编辑”（工具不应点）。
- `tests/fixtures/zl-real/`：**真实** Vue 2 + Element UI 2，按智联校园网申页面的结构和交互自行重建（不含网站的代码与样式）（`/zl-like/`，测试构建视为智联页面）。包含：只读展示 →“编辑”/“添加”、字段名只在 `label[for]`、只读日期框与“至今”快捷项、学校候选（含境外院校带出海外经历）、城市弹窗（省→市→区县、热门直辖市、期望城市多选“确定”）、语言证书弹窗、技能弹窗。`window.__fixture` 记录保存点击数、学校候选点击数、各表单值。
- `tests/fixtures/el-real/`：**真实** Vue 2 + Element UI（`/el1/` 为 1.4.13，与山东高速招聘平台同版本；`/el2/` 为 2.15）搭建的“我的简历”简历中心：左侧导航分子页面（基本信息 / 教育背景 / 工作履历），区块标题是普通 div 且外层类名含 menu，教育/工作记录点“添加”在弹窗里填写，右下角有跨域客服小窗。`window.__fixture` 记录保存点击数、提交事件、各表单的 Vue 状态。
- `tests/fixtures/el-like/`：按智联/企业招聘系统常见写法自行编写的 Element UI 风格页面：区块标题是普通 div、侧边导航里有同名文字、单选组/只读下拉/区间日期、禁用字段、一个同源内嵌表单框架和一个跨域（localhost）内嵌框架。同一页面也复制为 `/gp-like/other.html`，用来测“国聘适配器找不到区块时改用通用识别”。
- `tests/resumes/`：虚构简历的文字原稿（标准单栏、日期单独成行、左侧信息栏两栏、完整版）。`resume-realistic.*`：学校、单位、城市、证书真实存在，个人信息编造（txt / pdf / docx + 配套档案 `profile-realistic.json`），用于在真实网站上试学校候选、城市弹窗、证书字典。`resume-full.*`：全字段测试简历（txt / pdf / docx + 配套档案 `profile-full.json`），日期都写到日，含家庭成员、紧急联系人、期望薪资、体重/微信（自定义字段），用于一次完整试填；`resume-full.test` 检查除标题外每行都能识别。

测试构建（`dist-test/`）额外授予 `127.0.0.1` 权限，并把 `/gp-like/` 视为国聘页面；发布构建（`dist/`）不含这些。

## 手动测试（本人在浏览器里做，约 20 分钟）

准备：按[安装说明](安装说明.md)加载新版扩展文件夹（升级时点扩展卡片上的 ⟳，并刷新已打开的网页）。测试简历在 `测试简历/` 文件夹（或运行 `node scripts/make-test-resumes.mjs` 生成），全部是虚构信息。

### A. 简历自动识别（档案管理页）

| 步骤 | 预期 |
|---|---|
| 1. 档案管理页 →“删除全部本地数据”（先导出备份！）→ 页面顶部 | 黄色条：“还没有保存过档案……点保存后才会存进本机” |
| 2. “选择简历文件”→ `resume-standard.pdf` | 左侧出现原文，手机号标红；自动弹出“从简历中识别到的内容” |
| 3. 看弹窗 | 姓名 林示例、性别 女、出生日期 2001-05、籍贯 湖南省/长沙市、邮箱、求职意向“财务分析、审计”已勾选；**手机号、政治面貌未勾选**（标“敏感”）；教育 2 条、实习 2 条、项目 1、校园经历 1、荣誉 3、语言 2（CET6 560、IELTS 7.0）、证书 CPA“部分通过” |
| 4. 勾上手机号 →“填入选中的 N 项” | 右侧各栏被填上，填入的字段/经历是**黄色底**；顶部状态“有未保存的修改” |
| 5. 检查：教育第 2 条“毕业时间”勾着“至今”；实习第 1 条地区“北京市” | 与原文一致 |
| 6. 点“保存” | 绿色条：“已保存到本机。位置：……chrome.storage.local，键名 profile……”，并列出“教育 2 条 · 工作/实习 2 条……”；黄色底消失 |
| 7. 点“查看已保存内容” | 弹窗里是存储中的原始 JSON，能找到“示例证券股份有限公司” |
| 8. 按 F5 刷新档案页 | 内容都还在（证明真的保存了） |
| 9. 改一个字段（如英文名）→ 看顶部 → 点“放弃修改，恢复到已保存” | 先显示“有修改尚未保存”，放弃后恢复原值 |
| 10. 再选一次同一份简历 | 已有的经历显示“档案中已有”且不能勾选；已有值的字段显示“档案已有：…”且默认不勾选 |
| 11. 分别再试 `resume-twocolumn.docx`、`resume-sidebar.pdf`（左侧信息栏两栏） | 陈测试 / 王样例 的信息被正确识别；两栏版不会把左右两栏的内容串到一行 |
| 12. 换成你自己的真实简历试一次（不要发给别人） | 记下识别错或漏掉的项（只记“哪一类没识别”，不要记内容），反馈给开发者 |

### B. “添加一条”不跳到顶部

| 步骤 | 预期 |
|---|---|
| 滚动到“工作/实习经历”，点“＋ 添加一条工作/实习经历”，连续点 3 次 | 页面停在原处，新的一条展开并且光标在“工作性质”上；之前展开的记录保持展开 |
| 删除其中一条、点 ↑↓ 移动 | 页面不跳动 |

### C. 侧边栏认出网站（国聘、智联、企业官网）

| 步骤 | 预期 |
|---|---|
| 1. 打开国聘“申请简历”页 → 点工具栏图标打开侧边栏 | 第一次：显示“读取不到当前网页的地址”和“允许读取当前网页地址”按钮（这就是之前显示“当前网站 / 没有专用适配器”的原因） |
| 1b. 点“允许读取当前网页地址”→ 浏览器弹窗点“允许” | 顶部变成“国聘（…iguopin.com）”；以后不会再问 |
| 2. 档案还没保存时 | 提示“还没有已保存的档案……点保存”；保存后侧边栏自动更新 |
| 3. 点“扫描本页” | 列出基本信息、教育经历等区块，以及“添加并准备第 N 条”按钮 |
| 4. 打开国聘的其他页面（如职位详情页）→ 扫描 | 提示“国聘适配器没有在这个页面上找到……下面是通用识别结果” |
| 5. 打开智联招聘（社招）的在线简历编辑页（先点开一个“编辑”）→ 扫描 | 顶部显示“通用识别”，列出识别到的区块名、字段列表（高/中/低）；勾选后可点“填写选中的 N 项”，工具不点保存 |
| 6. 打开任一企业招聘官网的简历填写页 → 侧边栏 | 若显示“读取不到当前网页的地址”，点“允许读取当前网页地址”并同意；再点“扫描本页”，同意访问该网站 |
| 7. 企业官网扫描结果 | 有字段列表；若表单在其他网站的内嵌框架里，会提示“有 N 个来自其他网站的内嵌框架……无法读取” |

请把 C5–C7 的结果（截图里**遮住个人信息**）或“扫描诊断”报告发给开发者，用来决定哪个网站先做专用适配器。
