## 先看这四条

1. **填完一定要自己核对。** 标“中”的字段（大致对得上、日期只到月按 1 日补齐、推断值）现在也默认勾选并填写，侧边栏会写明原因。工具只负责填，对不对由你在网页上看过之后再点保存。政治面貌、婚姻、户口这类敏感项仍然只在完全确定时才填。
2. **在扩展管理页点“移除”会清空数据。** 档案、定制适配器和设置都存在浏览器里，移除扩展时会一起删掉。升级只需要覆盖文件夹再点刷新，不要点“移除”。从 0.8.1 及更早的版本升级到 0.9.0 是个例外：扩展的身份标识变了，旧数据不会自动带过来，升级前先“导出备份”，升级后“导入 JSON”（只需这一次）。
3. **定期“导出备份”。** 备份文件包含档案、定制适配器和设置（不含大模型 API 密钥），是明文，含个人信息，只存在自己的电脑或 U 盘里。0.8.1 及更早版本导出的备份只有档案。
4. **哪些网站真正试过。** 智联校园网申页在真实页面上核对过结构并试填过部分区块；Moka 申请页在真实页面上只读核对过结构，2026-11-12 由本人在一家企业的校招申请页上试填过一次（大部分栏目填上了；学校名称、专业名称两栏没填上，原因还没查明）；国聘、山东高速等其他网站只在按页面材料重建的本地测试页上验证过。第一次用时请逐项核对，有问题用“扫描诊断”导出报告。

## 自研组件的网站（Moka 等，0.10.0 起）

网站用自己写的组件（不是 antd、Element 这类通用组件库）时，工具按通用方式读和填：

- **能填**：文本框、多行文本、下拉、“年 + 月”下拉（单个和起止）、“至今”勾选、带候选的搜索框（学校、专业）。
- **标“需本人完成”**：日历式的日期（如出生日期）、省市县面板（如籍贯）、上传、声明勾选、证件号码。
- **学校和专业**：候选里没有和档案一字不差的，会选字面上最接近的一个，网页上标成黄色并在结果里写明，请核对。一个候选都搜不到时不填。
- **下拉的选项**：选项里没有档案里的值、但有一个字面上明显最接近时，选它并标“中”。政治面貌、婚姻这类敏感项不走这一步，只在完全相等时才填。
- **扫描时会把对上的下拉逐个点开读选项，再关上**，不选任何值。有的网站（如 Moka）会因此在必填的下拉下面显示红色的“必填项未填写”，填上后消失。
- **多条经历排在同一页**：网页上第 N 份表单对应档案第 N 条。不够时先在网页上点“添加”（或点侧边栏的“在网页上点‘添加’并重新扫描”），工具不会自己连续添加。Moka 按平台提示认；其他网站按结构推断：经历类区块里并排的几个容器装着同一套字段名，就算几条记录。推断不出来的情况：网页上这个区块只有一份表单（先在网页上点“添加”再重新扫描）；几条记录没有各自的容器、所有栏目平铺在一起（这时同名的栏目只填第一份）。
- **“至今”**：有的网站勾了“至今”就把结束的年、月拿掉。工具照样把这一栏认成起止时间，显示“某年某月 ~ 至今”，不会改动它。要改成具体的结束时间，请先在网页上取消“至今”再重新扫描。
- **Moka 上传简历后会重新解析并覆盖已填内容**：先上传简历，等十几秒解析完，再扫描填写。
- **撤销**：自研下拉没有可靠的清空方式，撤销时这些项会提示“无法安全恢复，请手动处理”。文本框可以撤销。
- **亲属、联系人的栏目**：一组表单里有“与本人关系”这类栏目、所在区块又不是本人信息的区块时，里面的姓名、电话不按你本人的资料填（标“低”）。
- **验证范围**：通用方式只在本地测试页上验证过（一套带 Moka 类名、一套换成中性类名）。真实 Moka 页面 2026-11-12 不登录只读核对过：区块和 55 个表单项的结构、年份和月份下拉的选项、弹层的位置、点空白处能关上、“添加”按钮；同日由本人在该页面上试填过一次，据填写后的诊断报告修了三处（“至今”勾上后起止时间被认成单个日期、页头的搜索框变出一个空区块、没有平台提示时同页的第二条记录不填）；学校名称、专业名称没填上的原因还没查明，期望城市的控件类型没核对。北森、飞书、大易等其他平台没有核对过，效果未知。
- **通用方式扫描不到的控件**：没有输入框的下拉和单选（整个用 div 画出来的）、跨域内嵌框架里的表单、Shadow DOM 里的表单。不能搜索、又只渲染一部分选项的长下拉，只能选到当前渲染出来的选项。富文本编辑框（contenteditable，0.12.0 起）按长文本栏填写，只在本地测试页上验证过，真实编辑器（Quill、wangEditor 等）没有逐个试过。
- **可选：让大模型从选项里挑**（设置里打开，默认关）。只用于下拉这类枚举字段、且选项里找不到档案里的值的时候；每次发送前显示全部要发的内容（字段名、你档案里这一项的值、网页选项），确认后才发。姓名、联系方式、证件和敏感项永远不发。挑出来的结果标“中”。未用真实付费 API 验证，自动化测试使用模拟接口。

## 功能边界

- **内置专用适配有两个站点**：国聘（`*.iguopin.com`）的申请简历页；智联校园网申“填写简历”页（`xiaoyuan.zhaopin.com/scrd/resume*`，2026-11-09 起；同日在本人已登录的 Chrome 里只读核对了真实页面全部区块的字段名、控件类型、下拉选项、技能字典、英语证书列表和选“至今”后表单重画的行为，夹具已按此更新；**完整的一次填写仍待本人在真实页面上确认**）。其他网站可以**生成定制适配器**（0.12.0 起可以不用大模型、按本机规则先对应好；也可以让大模型根据页面结构给出对应关系；都要你复核后保存），之后可执行填写。通用识别和定制适配器会点区块里的“添加”和只读单项区块的“编辑”（经历记录旁的“编辑”不点），但不识别“已保存记录”、不支持“存回档案”询问（这些依赖站点结构，需要内置适配器）。
- 定制适配器用大模型生成时只发送页面结构（字段名、控件类型、选项，并做兜底脱敏），不发送档案或页面上的值；生成质量取决于模型，未用真实付费 API 验证，自动化测试使用模拟接口。按本机规则生成不联网，只有把握大的字段直接写进对应表，其余在复核界面里显示“推测”，由你决定。
- **存回档案**：点页面“保存”且表单收起后询问；只写入勾选项。读取的是页面显示文字，再按词典反向换算（如“实习”→ 实习、“中国 / 北京市 / 海淀区”→ 地区）；换算不了的项不写回。新建记录缺必填项时不新建。
- **没有定制适配器的其他网站（智联招聘、企业招聘官网、企业“我的简历”简历中心等）是通用识别**：按区块列出字段、对应档案的哪一项、把握程度，**预览确认后填写**（2026-11-09 起；此前只预览）。“标签与档案字段名完全相等 + 区块吻合”为“高”，只有标签相等为“中”。2026-11-09 起“中”也默认勾选（先选最接近的一项、日期只到月按 1 日补齐），由本人在网页上核对后保存。能填写的组件库：原生表单（含浏览器自带的日期框 type=date / type=month，0.12.0 起）、antd、Element UI 1.x/2.x（Element Plus 只按类名兼容、未用真实库测试）；iView、Arco 等能识别，下拉和日期需手选；网站自研的组件见上一节。打开的“添加”弹窗会被识别并归到对应区块。**跨域内嵌框架**浏览器不允许读取，只会提示（右下角客服小窗等小框架不提示）。
- 通用识别的限制：Element 日期框若网站禁止键入，单个日期（年 / 月 / 日）会在日期面板上逐级点选，区间日期和带时间的日期仍只提示手动选择；同一区块同时展开多份表单、又认不出每份表单各自的容器时只填第一份（认得出来时按第 N 份对应档案第 N 条，见上一节）；只读的文字框（点开后要自己选的控件）不填；通用页面暂不支持“存回档案”询问；区块类别按标题判断（家庭成员、附件类为“需本人完成”）。没有分区块的单页报名表里出现“毕业院校 / 所学专业 / 学历 / 毕业时间”时，按你最高学历那一条填，标“中”（0.12.0 起；以前标“低”不填）。山东高速招聘平台只核对过未登录可见的“基本信息”页结构，登录后的教育/工作页未实测。
- **默认简历自动识别**使用本地规则。0.12.0 起认得模板里常见的写法：区块标题带英文副标题（“教育背景 EDUCATION”）、字间加空格（“教 育 背 景”）、带图标和编号、标题和内容在同一行；表格式简历（PDF 和 Word 的“姓名 | 王五 | 性别 | 男”，基本信息表里写的毕业院校、专业、学历会合成一条教育经历）；英文月份（Sep 2019）。自我评价、工作描述等长文本按原文保存（以前中文逗号会被换成英文逗号）。仍然识别不了：图片简历和扫描版 PDF、整份用文本框或图形拼出来的设计感简历、内容顺序被打乱的 PDF。识别结果一律先预览、本人勾选，填入后需核对并保存。窄栏里被折行的内容可能被拆开（如“Spring / Boot”），预览中可以取消勾选。
- 手机号、政治面貌等敏感项识别后默认不勾选；**证件号永远不会被识别填入**。
- **证书弹窗**：已支持（按 basic-info 的弹窗结构实现，真实国聘未验证）。会计类、审计类、金融类等分类下的真实证书名没有材料，别名表是推测的；找不到名称一致的项时只给候选、不自动选。
- **家庭成员**：档案里可以录入（简历识别也能认出），但网页上的家庭成员区块一律标“需本人完成”，不自动填写（避免把家人和本人的姓名、单位填串）。
- **当前版本不做**：国聘期望城市弹窗的填写、附件与证件照上传、导出加密、共享电脑模式；北森、大易、飞书等平台的专门适配（先用通用识别或定制适配器）。
- **不处理**：验证码、手机签名、实名锁定字段、声明类问题。
- **不生成任何文字**：长文本只原样插入你自己写的内容。
- **截图识别要发给大模型**（0.11.0 起）：本机没有读图能力，截图整张发给你配置的 API，需要能读图的模型；图里的证件号、手机号等也会发出，请先裁掉或打码。左栏显示的“原文”是大模型自己转写的文字，可能有错字，“原文依据”只能证明字段出自这段转写，不能证明转写和截图一致，请对照截图核对。只用模拟接口测过，没有用真实的读图模型验证；长截图（整页滚动截图）的识别效果没有测过。只写补充文字时在本机按规则识别，随手写的句子（不是“字段名：内容”）多半识别不出。
- 可选大模型 API 只在明确确认后发送简历文字或你选的截图。模型的事实理解仍需本人核对；未使用真实付费 API 验证，自动化覆盖模拟接口。0.12.0 起逐项核对模型的结果：日期写成“2019.09”、学历写成“本科”这类写法会自动换成档案用的格式；某一项格式不对或在原文里找不到依据，只丢这一项（预览里列出原因），其余照常填入（以前整份报错）。接口不支持 JSON 输出参数时会去掉这个参数自动重试一次。
- 扫描版（图片）PDF 无法提取文字（不做 OCR）；不支持 `.doc` 老格式。
- 同一窗口切换标签页保留内存中的进度；关闭侧栏或浏览器后不保留。页面刷新后撤销记录失效；已保存到网站的记录不能撤销。
- 项目经历按提供的页面结构适配；团队规模的区间下拉仍需手选。真实登录后网站未实测。
- 档案不加密存储（依赖电脑本身的开机密码）。卸载扩展会清除档案，请先导出备份。导出的备份文件也是明文。
- 备份文件含档案、定制适配器和设置；大模型 API 的地址、模型名和密钥不导出，换电脑后需要重新填写。

## 权限

- 安装时只有：读取存储、注入脚本、侧边栏、activeTab。**安装时不申请任何网站的访问权限**（发布检查 `npm run check:network` 会拦住 host_permissions）。
- 按需（你点按钮时才申请，各一次）：
  1. “读取标签页网址”：侧边栏需要知道当前是哪个招聘网站。没有它时侧边栏显示“读取不到当前网页的地址”和授权按钮。
  2. 某个网站的访问权限：第一次在该网站点“扫描本页”时申请。
  3. API 域名权限：确认发送简历（档案页）或生成定制适配器（侧边栏）时按指定地址申请。

- Chrome 116 及以上；Edge 新版。测试浏览器和本轮结果见测试方法文档。
- 正式版 Chrome 137 起不再支持用命令行参数加载扩展，所以 Chrome 正式版无法跑自动化测试；手动“加载已解压的扩展程序”不受影响。
- 浏览器不支持侧边栏时，点图标会改为打开一个独立小窗口，功能相同（未在实机上触发验证）。
