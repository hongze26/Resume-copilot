# 已知限制

版本：0.9.0（2026-11-09）。

## 先看这四条

1. **填完一定要自己核对。** 标“中”的字段（大致对得上、日期只到月按 1 日补齐、推断值）现在也默认勾选并填写，侧边栏会写明原因。工具只负责填，对不对由你在网页上看过之后再点保存。政治面貌、婚姻、户口这类敏感项仍然只在完全确定时才填。
2. **在扩展管理页点“移除”会清空数据。** 档案、定制适配器和设置都存在浏览器里，移除扩展时会一起删掉。升级只需要覆盖文件夹再点刷新，不要点“移除”。从 0.8.1 及更早的版本升级到 0.9.0 是个例外：扩展的身份标识变了，旧数据不会自动带过来，升级前先“导出备份”，升级后“导入 JSON”（只需这一次）。
3. **定期“导出备份”。** 备份文件包含档案、定制适配器和设置（不含大模型 API 密钥），是明文，含个人信息，只存在自己的电脑或 U 盘里。0.8.1 及更早版本导出的备份只有档案。
4. **哪些网站真正试过。** 智联校园网申页在真实页面上核对过结构并试填过部分区块；国聘、山东高速等其他网站只在按页面材料重建的本地测试页上验证过，第一次用时请逐项核对，有问题用“扫描诊断”导出报告。

## 功能边界

- **内置专用适配有两个站点**：国聘（`*.iguopin.com`）的申请简历页；智联校园网申“填写简历”页（`xiaoyuan.zhaopin.com/scrd/resume*`，2026-11-09 起；同日在本人已登录的 Chrome 里只读核对了真实页面全部区块的字段名、控件类型、下拉选项、技能字典、英语证书列表和选“至今”后表单重画的行为，夹具已按此更新；**完整的一次填写仍待本人在真实页面上确认**）。其他网站可以**生成定制适配器**（大模型根据页面结构给出对应关系，你复核后保存），之后可执行填写。通用识别和定制适配器会点区块里的“添加”和只读单项区块的“编辑”（经历记录旁的“编辑”不点），但不识别“已保存记录”、不支持“存回档案”询问（这些依赖站点结构，需要内置适配器）。
- 定制适配器只发送页面结构（字段名、控件类型、选项，并做兜底脱敏），不发送档案或页面上的值；生成质量取决于模型，未用真实付费 API 验证，自动化测试使用模拟接口。
- **存回档案**：点页面“保存”且表单收起后询问；只写入勾选项。读取的是页面显示文字，再按词典反向换算（如“实习”→ 实习、“中国 / 北京市 / 海淀区”→ 地区）；换算不了的项不写回。新建记录缺必填项时不新建。
- **没有定制适配器的其他网站（智联招聘、企业招聘官网、企业“我的简历”简历中心等）是通用识别**：按区块列出字段、对应档案的哪一项、把握程度，**预览确认后填写**（2026-11-09 起；此前只预览）。“标签与档案字段名完全相等 + 区块吻合”为“高”，只有标签相等为“中”。2026-11-09 起“中”也默认勾选（先选最接近的一项、日期只到月按 1 日补齐），由本人在网页上核对后保存。能填写的组件库：原生表单、antd、Element UI 1.x/2.x（Element Plus 只按类名兼容、未用真实库测试）；iView、Arco 等能识别，下拉和日期需手选。打开的“添加”弹窗会被识别并归到对应区块。**跨域内嵌框架**浏览器不允许读取，只会提示（右下角客服小窗等小框架不提示）。
- 通用识别的限制：Element 日期框若网站禁止键入，单个日期（年 / 月 / 日）会在日期面板上逐级点选，区间日期和带时间的日期仍只提示手动选择；同一区块同时展开多份表单时只填第一份；通用页面暂不支持“存回档案”询问；区块类别按标题判断（家庭成员、附件类为“需本人完成”）。山东高速招聘平台只核对过未登录可见的“基本信息”页结构，登录后的教育/工作页未实测。
- **默认简历自动识别**使用本地规则：常见中文简历（单栏、左侧信息栏两栏）效果较好；表格式简历、图片简历、英文简历、版式特殊的简历识别率会下降。识别结果一律先预览、本人勾选，填入后需核对并保存。窄栏里被折行的内容可能被拆开（如“Spring / Boot”），预览中可以取消勾选。
- 手机号、政治面貌等敏感项识别后默认不勾选；**证件号永远不会被识别填入**。
- **证书弹窗**：已支持（按 basic-info 的弹窗结构实现，真实国聘未验证）。会计类、审计类、金融类等分类下的真实证书名没有材料，别名表是推测的；找不到名称一致的项时只给候选、不自动选。
- **家庭成员**：档案里可以录入（简历识别也能认出），但网页上的家庭成员区块一律标“需本人完成”，不自动填写（避免把家人和本人的姓名、单位填串）。
- **当前版本不做**：国聘期望城市弹窗的填写、附件与证件照上传、导出加密、共享电脑模式；北森、大易、Moka 等内置专用适配器（先用通用识别或定制适配器）。
- **不处理**：验证码、手机签名、实名锁定字段、声明类问题。
- **不生成任何文字**：长文本只原样插入你自己写的内容。
- 可选大模型 API 只在明确确认后发送简历文字。模型的事实理解仍需本人核对；未使用真实付费 API 验证，自动化覆盖模拟接口。
- 扫描版（图片）PDF 无法提取文字（不做 OCR）；不支持 `.doc` 老格式。
- 同一窗口切换标签页保留内存中的进度；关闭侧栏或浏览器后不保留。页面刷新后撤销记录失效；已保存到网站的记录不能撤销。
- 项目经历按提供的页面结构适配；团队规模的区间下拉仍需手选。真实登录后网站未实测。
- 档案不加密存储（依赖电脑本身的开机密码）。卸载扩展会清除档案，请先导出备份。导出的备份文件也是明文。
- 备份文件含档案、定制适配器和设置；大模型 API 的地址、模型名和密钥不导出，换电脑后需要重新填写。

## 权限

- 安装时只有：读取存储、注入脚本、侧边栏、activeTab。**安装时不申请任何网站的访问权限**（发布检查 `npm run check:network` 会拦住 host_permissions）。
- 按需（你点按钮时才申请，各一次）：
  1. “读取标签页网址”：侧边栏需要知道当前是哪个招聘网站。没有它时侧边栏显示“读取不到当前网页的地址”和授权按钮。
  2. 某个网站的访问权限：第一次在该网站点“扫描本页”时申请。
  3. API 域名权限：确认发送简历（档案页）或生成定制适配器（侧边栏）时按指定地址申请。

## 浏览器

- Chrome 116 及以上；Edge 新版。测试浏览器和本轮结果见测试方法文档。
- 正式版 Chrome 137 起不再支持用命令行参数加载扩展，所以 Chrome 正式版无法跑自动化测试；手动“加载已解压的扩展程序”不受影响。
- 浏览器不支持侧边栏时，点图标会改为打开一个独立小窗口，功能相同（未在实机上触发验证）。
